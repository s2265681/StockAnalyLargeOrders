## 第六步：微信认证（个体工商户 30 元/次）

路径：**设置 → 基本设置 → 微信认证 → 开始认证**

| 项目 | 说明 |
|------|------|
| 费用 | **个体工商户 30 元/次**（限时优惠；有限公司等企业主体为 300 元/次，以支付页显示为准） |
| 材料 | 营业执照、经营者身份证、对公账户或法人银行卡（按页面提示） |
| 审核时间 | 通常 1–5 个工作日 |
| 开票 | 可开电子发票 |

认证通过后，后台显示 **已认证**，主体为个体工商户。

---

## 第七步：绑定商户号

认证通过后：

1. 登录 [微信支付商户平台](https://pay.weixin.qq.com)
2. **产品中心 → AppID 账号管理 → 关联 AppID → 新增授权**
3. 填写新小程序 **AppID**（在小程序后台 **设置 → 基本设置** 查看）
4. 勾选同意协议 → 提交
5. 回到 **小程序后台 → 微信支付 → 商户号管理** → 确认授权

主体一致时，一般几分钟内生效。

## 第八步：更新项目配置

拿到小程序 AppID 后（形如 `wxxxxxxxxxxx`）：

### 1. 服务器 `backend/.env`
```bash
WECHAT_APP_ID=wx你的新小程序AppID
WECHAT_PAY_ENABLED=1
```

### 2. 本地 `backend/.env`（同步）

### 3. 若移动端也要用新小程序，改 `mobile/project.config.json`：
```json
"appid": "wx你的新小程序AppID"
```

### 4. 重启后端并验证
```bash
cd backend
python3 scripts/check_wechat_pay_config.py
pm2 restart StockAnalysisLargeOrders   # 或你的部署方式
```

### 5. 测试支付
用 **日度 VIP ¥0.01** 在 PC 网站扫码测一笔。
