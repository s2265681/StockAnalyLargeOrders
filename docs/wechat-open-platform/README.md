## 五、审核通过后的下一步

1. 复制网站应用 **AppID**
2. 登录 [微信支付商户平台](https://pay.weixin.qq.com) → 产品中心 → AppID 账号管理 → 新增授权
3. 登录开放平台 → 网站应用 → 微信支付 → 确认关联
4. 配置 `backend/.env` 中的 `WECHAT_APP_ID` 等参数
